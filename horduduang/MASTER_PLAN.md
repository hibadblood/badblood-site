## 3) Full auto แทน HUMAN_REVIEW — เกราะ 5 ชั้น (ไม่มีคิวคน)

1. **ก่อนเปิดศาสตร์:** golden test vectors ต่อ method + red-team ชุด AT-001..021 ผ่านครบ
2. **ทุกข้อความ:** crisis/prohibited classifier ก่อนคำนวณ → calculator deterministic → LLM อธิบายจาก facts เท่านั้น → output scan อัตโนมัติ (ban list, การันตี, เลข, ขู่) → ส่ง
3. **fail closed:** ชิ้นไหนสแกนไม่ผ่าน = ไม่ส่ง + คืนเครดิต/แจ้งลูกค้าอัตโนมัติ + เข้า log
4. **สุ่มตรวจย้อนหลัง:** ระบบสุ่มตัวอย่าง output แนบมากับรายงานรายสัปดาห์ให้เฟียร์กวาดตา
5. **kill switch ต่อ persona/method/การจ่ายเงิน** — ปิดจุดเดียวไม่ล้มทั้งหอ
