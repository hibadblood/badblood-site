# หอดูดวง — โปรเจกต์แยก (แยกขาดจากเว็บ BAD BLOOD)

โฟลเดอร์นี้คือดราฟโปรเจกต์ "หอดูดวง" ทั้งชุด — **ห้ามปนกับไฟล์เว็บ BAD BLOOD
ที่ root ของ repo** และตอน deploy จริงต้องแยกไปโฮสต์/repo ของตัวเอง
(แบรนด์นี้ต้องไม่มีร่องรอยโยงกลับมาที่ BAD BLOOD ในทุกของที่ลูกค้าเห็น)

## ไฟล์ในชุดนี้

| ไฟล์ | คืออะไร |
|---|---|
| `index.html` | เว็บไซต์เต็มหน้าเดียว จบในไฟล์เดียว (CSS/JS ฝังใน ไม่มี dependency นอกจาก Google Fonts) |
| `PERSONAS.md` | ทำเนียบหมอดู 12 สำนัก + system prompt ร่างของ 8 ตัวใหม่ + กฎเหล็ก/ระบบป้องกันฝั่งแชต |
| `GROWTH.md` | ผลรีเสิร์ชตลาดไทย + สินค้าที่ควรขายต่อ + แผนช่องทาง + ระบบป้องกันกฎหมาย/ความเชื่อใจ |
| `REFERRAL.md` | เฟส 2.5 — สเปกระบบ "ชวน ๑ ดูฟรี ๑" + การ์ดแชร์ 4:5 + กันโกง + acceptance tests |
| `FREE_READING.md` | เฟส 2.6 — สเปกผูกดวงแรกพบฟรี: โครง 5 จังหวะ, system prompt, ban list, ตัวอย่างทอง, A/B + ตัววัด |

## ก่อนเปิดจริง — เช็กลิสต์

1. **แทนลิงก์ LINE:** ค้นหา `lin.ee/XXXXXX` ใน `index.html` — มี **21 จุด**
   ทุกจุดมี `utm_content` ต่างกันไว้ตามพฤติกรรมคนกด (nav, hero, card, seer-*,
   price-*, taksa-wallpaper, gate) อย่าลบ UTM ทิ้ง
2. **โลโก้จริง:** ไฟล์ `logo-hordooduang.svg` ไม่อยู่ใน repo นี้ — หน้าเว็บใช้
   wordmark ตัวอักษร + ดาว ✦ ไปก่อน ได้ไฟล์จริงเมื่อไรค่อยวางแทนใน hero/topbar
3. **รูปหน้าหมอดู:** การ์ดหมอดูใช้ตราอักษร (seal) เป็น placeholder —
   ได้ภาพเจนจาก Master File แล้วค่อยแทนใน `.seal` ของแต่ละการ์ด
4. **ตาราง lookup:** ค่าใน `TAKSA` (JS) กับตาราง fallback (HTML) ใน `index.html`
   ต้องตรงกับตาราง lookup ของ engine เสมอ — และตารางฝั่ง engine ไม่ได้มีแค่ทักษา:
   ผูกดวงแรกพบ (เฟส 2.6) ใช้เพิ่มอีก 4 ชุด (deity_trait / ฐานดวง trait_keys /
   ช่วงดวง+ธีม / hook — ดู FREE_READING.md ข้อ 2)
   **แหล่งความจริงเดียวกัน ทุกที่ห้ามขัดกัน** ตอนนี้ใช้ค่าตำราทักษากระแสหลัก
   ให้เทียบกับตาราง canonical ใน HORDUDUANG_MASTER_v1.md ก่อนเปิด
5. **แถบ "เปิดเร็ว ๆ นี้"** ในห้องราคา: โชว์บริการใหม่ 5 ตัวโดยไม่มีราคา —
   รอเฟียร์เคาะ จะคงไว้หรือถอดออกก็แก้ที่ `.soon` จุดเดียว
6. **ห้ามยิงแอดก่อนผูกดวงแรกพบใช้งานจริงในแชต** — เว็บสัญญาของฟรีชิ้นนี้ไว้ 5 จุด
   (hero, วิธีเข้าหอ, ห้องราคา, FAQ, ประตูท้ายหอ) แอดที่มาก่อนของพร้อม = เผาเงินและเผาชื่อ
   ลำดับวันเปิดอยู่ใน GROWTH.md ข้อ 7
7. **ถ้าเครดิตชวนเพื่อน (2.5) ยังไม่เปิดในวันเปิดตัว** — ต้องปิดคอลัมน์ "ชวนเพื่อน"
   ใน `.free-lead` + FAQ ข้อชวนเพื่อนบนเว็บชั่วคราว (ห้ามสัญญาสิ่งที่ระบบยังไม่ให้ —
   กติกาเต็มใน GROWTH.md ข้อ 7)

## Deploy

ไฟล์เดียวจบ — โฮสต์ static ที่ไหนก็ได้ที่เฟียร์คุมเอง (Cloudflare Pages
โปรเจกต์ใหม่แยกบัญชี/โปรเจกต์จากเว็บ BAD BLOOD ก็ได้) ไม่มี build step
ห้ามผูกกับบริการที่โยงกลับมาที่ผู้ช่วย AI หรือ BAD BLOOD

## กติกาที่ไฟล์นี้ทำตาม (อย่าเผลอแก้ทิ้ง)

- เนื้อหามองเห็นได้เสมอแม้ JS พัง — JS เป็นแค่ตัวเพิ่มลูกเล่น
  (`js-only` / `no-js-only` คุมสองโหมด)
- เคารพ `prefers-reduced-motion` ทุกเอฟเฟกต์
- ไม่ใช้ localStorage/sessionStorage
- ราคาบนหน้าเว็บมีเฉพาะ 4 ตัวที่ล็อก: ๙๙ / ๒๔๙ / ๑๙๙ / ๓๙๙
- บรรทัด disclosure ปรากฏตามตัวอักษรในห้องราคาและท้ายหอ
- ไม่มีตัวเลขอวดอ้าง (ยอดลูกค้า/รีวิว) ที่ยังไม่มีจริง
