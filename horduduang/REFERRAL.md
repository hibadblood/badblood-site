## 1) กลไก (ตามที่อนุมัติ)

| ข้อ | กติกา |
|---|---|
| ลิงก์ชวน | ทุก user มีลิงก์ add-friend เฉพาะตัว + `ref` code ผูก user id |
| รางวัลผู้ชวน | เพื่อนใหม่**เพิ่มเพื่อนสำเร็จ**ผ่านลิงก์ → ผู้ชวนได้เครดิต "ถามฟรี ๑ เรื่อง" (มูลค่า = SKU ฿99 เท่านั้น) |
| รางวัลเพื่อนใหม่ | ผูกดวงแรกพบฟรี — เหมือนผู้ใช้ใหม่ทุกคน (ไม่มีของพิเศษเพิ่ม กันสร้างแรงจูงใจปั่นบัญชี) |
| เพดาน | ๓ เครดิต/เดือนปฏิทิน/คน — เกินแล้วระบบขอบคุณแต่ไม่แจก |
| ยกเลิกเครดิต | เพื่อนใหม่ unfollow/บล็อกภายใน ๗ วัน → เครดิตจากคนนั้นถูกยกเลิก |
| ขอบเขตของฟรี | เครดิตใช้ได้กับถามด่วน ฿99 เท่านั้น — เจาะลึก ฿249 / วอลเปเปอร์ ฿199 **ไม่มีทางฟรี**จาก referral ทุกกรณี |
| น้ำเสียง | ข้อความแจ้งเครดิตเขียนในเสียง persona ที่ user คุยล่าสุด |

## 2) โครงข้อมูล (ปรับชื่อตามคอนเวนชันของตอบแทนได้)

```
users:      line_user_id (PK) · ref_code (unique, สั้น อ่านง่าย เช่น HD7K2M)
            · referred_by (nullable) · last_persona · created_at
referrals:  id · referrer_id · referee_id (unique — คนหนึ่งถูกชวนได้ครั้งเดียว)
            · followed_at · status: pending | confirmed | revoked
credits:    id · user_id · referral_id · sku: 'ask99'
            · state: pending | active | used | revoked
            · granted_at · activates_at · used_at · order_id (nullable)
```

**สองทางเลือกตามบรีฟ (เลือกตามที่โครงตอบแทนทำง่ายกว่า):**
- **ทาง A — pending ๗ วัน:** เครดิตเข้าเป็น `pending`, `activates_at = followed_at + 7d`
  เพื่อน unfollow ก่อนครบ → `revoked` เงียบ ๆ / ครบ ๗ วันยัง follow → `active` + แจ้งในแชต
  (สะอาดสุด ไม่มีการหักย้อนหลัง — **แนะนำทางนี้**ถ้า webhook `unfollow` ฟังได้อยู่แล้ว)
- **ทาง B — เข้าเลย หักย้อนหลัง:** เครดิต `active` ทันที แจ้งทันใจกว่า
  ถ้าเพื่อน unfollow ใน ๗ วันและเครดิตยังไม่ถูกใช้ → `revoked` + แจ้งสั้น ๆ
  ถ้าใช้ไปแล้ว → หักไม่ได้ (คำทำนายส่งแล้ว) ให้บวก `abuse_score` ผู้ชวนแทน

ทาง A ผู้ชวนต้องรอ ๗ วัน — ชดเชยด้วยข้อความ "สิทธิ์กำลังบ่ม" ที่บอกวันใช้ได้ชัดเจน
(ดูเทมเพลตข้อ 5) เพื่อไม่ให้ความตื่นเต้นหาย

## 3) กันโกง (เพิ่มจากบรีฟ — กลไกเดิม แค่กันรูรั่ว)

1. **กันชวนตัวเอง:** referee ต้องเป็น user ใหม่จริง (ไม่มี row เดิมใน users) และ
   `referee_id != referrer_id` — เคยเป็นเพื่อนแล้ว unfollow แล้วกลับมา = ไม่นับ
2. **เพดานนับที่ "แจก" ไม่ใช่ "คงเหลือ":** เครดิตที่ ๔ ในเดือนเดียว (นับ pending+active
   ที่ granted ในเดือนนั้น) → ไม่สร้าง record ใหม่ ตอบขอบคุณอย่างเดียว
3. **สัญญาณฟาร์มบัญชี:** ผู้ชวนที่เพื่อนใหม่ >50% ไม่เคยส่งข้อความใด ๆ เลย ภายใน ๗ วัน
   → ตั้งธง review, หยุดแจกเครดิตชั่วคราวแบบเงียบ (ไม่ต้องประจาน) — log ให้เฟียร์ดู
4. **เครดิตหมดอายุ ๙๐ วัน** นับจาก active *(ตัวเลขเสนอ — เฟียร์เคาะ)* กัน liability ค้างยาว
5. ทุก event เขียน log: granted / activated / used / revoked + เหตุผล — ต่อเข้า
   BAD BLOOD LEDGER ฝั่ง internal เป็น cost center "referral" (มูลค่าเครดิตที่ถูกใช้จริง)

## 4) การ์ดแชร์ (ตัวคูณหลัก) — SPEC

และลิงก์ชวนเฉพาะตัวของ user

## 5) เทมเพลตข้อความแจ้งเครดิต (เสียง persona)

กติกากลาง: บอก 3 อย่างเสมอในทุกข้อความเครดิต — ได้อะไร (ถามด่วนฟรี 1 เรื่อง) /
ใช้กับอะไรได้ (ถามด่วน ฿99 ทุกสำนัก — SKU เดียวเท่านั้น) / เหลือกี่สิทธิ์ในเดือนนี้
— ห้ามเว้นเงื่อนไขให้ไปเจอทีหลัง (คำสัตย์ข้อ ๕)
ตัวเลขในข้อความแชตใช้เลขอารบิกตามตัวอย่างทอง (เลขไทยใช้บนเว็บ/เอกสาร)
ถ้าเลือกทาง A (pending): ทุก persona ต้องมี 2 เทมเพลต — ตอนได้สิทธิ์ (pending)
และตอนสิทธิ์ใช้ได้จริง (active วันครบ 7 วัน) โดยเทมเพลต active ต้องครบ 3 อย่างเสมอ

- **อาจารย์ดาต้า (active):** "ข้อมูลอัปเดตค่ะ — เพื่อนที่คุณชวนเข้ามาผูกดวงเรียบร้อย
  สิทธิ์ถามด่วนฟรี 1 เรื่องเข้าบัญชีคุณแล้ว ใช้กับถามด่วนได้ทุกสำนัก
  (เดือนนี้รับได้อีก 2 สิทธิ์ค่ะ)"
- **ไพ่ลั่น (active):** "ไพ่เพิ่งกระซิบว่ามีคนเข้ามาเพราะคุณ 1 คน — สิทธิ์ถามด่วนฟรี
  1 เรื่องเป็นของคุณแล้ว หยิบเรื่องสั้น ๆ ที่ค้างใจมาถามด่วนได้กับสำนักไหนก็ได้
  (เดือนนี้รับได้อีก 2 สิทธิ์)"
- **อาม่าเฮง (active):** "เฮงแท้ ๆ ลูกชวนเพื่อนมาเพิ่มอีกคน อาม่าให้สิทธิ์ถามด่วนฟรี
  1 เรื่องเป็นน้ำใจ ใช้กับถามด่วนได้กับหมอทุกคนในหอ (เดือนนี้เหลือรับได้อีก 2 สิทธิ์นะ)"
- **ตีสาม (pending — ทาง A):** "มีคนตามแสงของคุณเข้ามากลางดึก 1 คน... สิทธิ์ถามด่วนฟรี
  1 เรื่องของคุณกำลังบ่มอยู่ ครบ 7 วัน (ใช้ได้ [วันที่]) ผมจะปลุกมาบอกเอง —
  ใช้ถามด่วนได้ทุกสำนัก เดือนนี้คุณรับได้อีก 2 สิทธิ์"
- เพดานเต็ม (กลาง): "เดือนนี้คุณรับสิทธิ์ครบ 3 ครั้งแล้ว — ขอบคุณที่พาคนมาหอเยอะขนาดนี้
  เพื่อนที่มาต่อจากนี้ยังได้ผูกดวงแรกพบฟรีเหมือนเดิม ส่วนสิทธิ์ของคุณจะกลับมารับได้ใหม่
  ต้นเดือนหน้า"

## 6) ตัวคูณเสริม (เสนอเพิ่ม — กลไกเดียวกับที่อนุมัติ ไม่มี share-gate / รอเฟียร์เคาะก่อนทำ)

1. **การ์ดสมพงศ์ฉบับคู่** — ดวงสมพงศ์เป็นสินค้า ๒ คนโดยธรรมชาติ การ์ดผลคู่ ๑ ใบ
   มี QR สองอัน (ลิงก์ชวนของทั้งคู่) — แรงสุดในไลน์อัปตามรีเสิร์ช
2. **ดวงประจำสัปดาห์ฟรี (opt-in)** — broadcast ทุกเช้าจันทร์ในเสียง persona ที่ user ใช้ล่าสุด
  ปิดท้ายด้วยการ์ดแชร์ประจำสัปดาห์ — retention loop ที่ LINE ดูดวงพิสูจน์แล้ว (เช็กต้นทุน broadcast ก่อน)
3. **วอลเปเปอร์ฟรีตามเทศกาล (generic)** — แจกแบบไม่ personalized ช่วงปีใหม่/ตรุษจีน/ดาวพักร์
   เป็น lead magnet (สูตร Mootae: 30–40k แชร์/โพสต์) → ตัวจ่ายคืออัปเกรด "ฉบับดวงคุณคนเดียว" ฿199
4. **โค้ดชวนบนการ์ดทุกใบ** — ทำแล้วในข้อ 4 (QR) — ไม่ต้องมีระบบแยก

## 7) Acceptance tests (เพิ่มจากชุดเดิม)

1. เพื่อนใหม่เพิ่มเพื่อนผ่านลิงก์ ref → เครดิตเข้าผู้ชวน (ตามทาง A: pending พร้อม activates_at / ทาง B: active)
2. เพื่อนคนนั้น unfollow ภายใน ๗ วัน → เครดิต revoked, ผู้ชวนไม่ได้ใช้
3. ชวนสำเร็จครั้งที่ ๔ ในเดือนเดียว → ไม่มีเครดิตใหม่ + ได้ข้อความขอบคุณแบบเพดานเต็ม
4. เครดิตใช้ซื้อถามด่วน ฿99 ได้ / พยายามใช้กับเจาะลึก ฿249 หรือวอลเปเปอร์ ฿199 → ระบบปฏิเสธสุภาพ เสนอใช้กับถามด่วนแทน
5. user เดิมถูกชวนซ้ำ / ชวนตัวเอง → ไม่เกิด referral record
6. ข้อความแจ้งเครดิตมาในเสียง persona ล่าสุดของ user จริง
7. การ์ดแชร์: ไม่มีวันเกิด/ข้อมูลส่วนตัวบนการ์ด, ประโยคเด่นไม่ติด ban list, QR สแกนแล้วไปลิงก์ ref ของเจ้าของการ์ด
