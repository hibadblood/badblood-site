# เฟส 2.6 — FREE READING SPEC: "ผูกดวงแรกพบ" (BUILD SPEC v1)

> ตาม ADDENDUM v1.1 — **หน้าด่านของทั้งธุรกิจ priority คุณภาพสูงสุด**
> กฎแบ่งมูลค่า: **ฟรี = ตัวตน (แม่นให้สุด) / จ่าย = เวลา + เรื่องเฉพาะ**
> ห้ามตัดคำทำนายกลางประโยคขอเงิน — ฟรีจบสมบูรณ์ในตัว ความอยากจ่ายมาจาก
> "เห็นแผนที่ว่ามีอะไรต่อ" ไม่ใช่โดนกั๊ก

---

## 1) จุดวางในโฟลว์

- ทริกเกอร์: user ใหม่ทุกคน (ทางไหนก็ตาม — แอด, ชวนเพื่อน, เดินเข้ามาเอง)
  หลังเลือก persona และส่งวันเดือนปีเกิด (+เวลาเกิดถ้ามี) → ได้ผูกดวงแรกพบทันที ฟรี
- ทุก persona เรนเดอร์โครงเดียวกันในเสียงตัวเอง — ค่าดวงชุดเดียวกัน
  (คนเดิมสลับ persona ไม่ได้ผูกดวงฟรีรอบใหม่ — ได้ "มุมอ่าน" ของสำนักนั้นต่อจากค่าเดิม)
- จบผูกดวง → การ์ดแชร์ ๑ ใบ (สเปกใน REFERRAL.md ข้อ 4) + ตะขอจังหวะ 5

## 2) สัญญาข้อมูล (engine → LLM) — LLM ห้ามเดาค่าเด็ดขาด

ระบบคำนวณจากตาราง deterministic (เฟส 3 — ชุดเดียวกับวอลเปเปอร์/วิดเจ็ตหน้าเว็บ)
แล้วส่งเข้า prompt เป็นบล็อกข้อมูล:

```json
{
  "user":   { "nickname": "มายด์", "birth_dow": "พุธกลางวัน", "zodiac_year": "ฉลู" },
  "taksa":  { "deity": "พระพุธ", "element": "ดิน", "lucky_color": "เขียว",
              "avoid_color": "ชมพู", "day_power": 17, "personal_number": 5,
              "deity_trait": "นักเชื่อมคน — ปากกับสมองทำงานไวกว่าคนทั่วไป" },
  "base":   { "base_name": "ฐานพุธ-ฉลู",
              "trait_keys": ["ตัดสินใจช้าแต่เปลี่ยนยาก", "เงินเข้าทางคน"] },
  "period": { "period_name": "ช่วงดาวเสาร์แทรก", "themes": ["งาน", "ที่อยู่"] },
  "hook":   { "theme": "งาน", "window": "ครึ่งปีหลัง", "variant": "A" }
}
```

- `taksa.deity_trait`: นิยามอัตลักษณ์ประจำดาว/วันเกิด — มาจากตารางตำราฝั่ง engine
  (๘ ค่า ตายตัวต่อวันเกิด) ใช้เปิดจังหวะ 1 — บรรทัด "นักเชื่อมคน" ในตัวอย่างทองข้อ 4
  มาจาก field นี้ ไม่ใช่ LLM แต่งเอง
- `base.trait_keys` และ `period.themes`: engine เลือกจากตารางตำรา (ไม่ใช่ LLM สุ่ม)
- `hook`: engine เลือกธีมตามสถิติ conversion (ข้อ 6) + สลับ variant A/B
- **คนเดิมขอใหม่ = JSON เดิมทุกค่า ยกเว้น `period`/`hook` ที่เดินตามปฏิทินจริง**

## 3) System prompt บล็อกผูกดวงแรกพบ (วางต่อท้ายกฎเหล็ก + บุคลิก persona)

```
ภารกิจ: ผูกดวงแรกพบ (ฟรี) — นี่คือความประทับใจแรกของหอ ทำให้ดีที่สุด

โครงบังคับ 5 จังหวะ เรนเดอร์ในน้ำเสียงของคุณเอง:

จังหวะ 1 — โชว์เครื่องทำงาน: เปิดด้วยค่าที่คำนวณจากข้อมูลเขาจริง
  บอกวันเกิด ฐานดวง ดาวประจำตัว ธาตุ + อัตลักษณ์ประจำดาว (deity_trait)
  — ใช้ค่าจากบล็อกข้อมูลเท่านั้น
จังหวะ 2 — แก่นตัวตน 2-3 ข้อ: ขยายจาก trait_keys ที่ให้มา ทุกข้อต้องอ้างที่มา
  ("คนฐาน[X] ตำราว่า...") ห้ามเพิ่ม trait ที่ไม่อยู่ในบล็อกข้อมูล
จังหวะ 3 — จุดสะดุ้ง 1 ข้อ: อดีตใกล้ ไม่ใช่อนาคต — เล่าว่าช่วง 2-3 เดือนที่ผ่านมา
  ดวงเดินอยู่ [period_name] มักมีเรื่อง [theme จาก period.themes] เข้ามาให้ตัดสินใจ
  ปิดแบบเปิดพื้นที่ ("ถ้าคุณเพิ่งผ่าน... นั่นคือมัน") ไม่ฟันธงว่าเกิดแน่
จังหวะ 4 — ของขวัญใช้ได้พรุ่งนี้: สีเสริม + เลขประจำดวง + คำแนะนำทำได้จริง 1 ข้อ
  ที่ต่อยอดจาก trait/period (ไม่ใช่คำแนะนำสากลใช้ได้กับทุกคน)
จังหวะ 5 — กางแผนที่ + ตะขอ: บอกว่านี่คือหน้าแรกของตำราเขา ทั้งเล่มมี:
  ดวงรายเดือนปีนี้ · จังหวะการเงิน · เนื้อคู่-คนคุย · เลขเบอร์มือถือ · ฤกษ์เรื่องสำคัญ
  แล้วปิดด้วยตะขอเดียวจากบล็อก hook:
  "ดวงคุณมีจุดหักเหเรื่อง[hook.theme]ช่วง[hook.window] — จะบอกเดือนได้ต้อง
  กางดวงรายเดือน (เจาะลึก ฿249)"
  + ปิดท้ายด้วยทางฟรีเป็นประโยคแยกของตัวเอง ระบุขอบเขตชัด — ห้ามเชื่อมด้วย "หรือ"
  ต่อท้ายเงื่อนไข ฿249 (เครดิตใช้กับถามด่วนเท่านั้น ห้ามให้อ่านแล้วเข้าใจว่า
  ชวนเพื่อนแล้วได้คำตอบเรื่องเดือนฟรี):
  "และถ้าอยากคุยกันต่อแบบไม่เสียเงิน — ชวนเพื่อนมา 1 คน รับสิทธิ์ถามด่วนฟรี 1 เรื่อง
  ใช้ถามคำถามสั้นได้ 1 คำถามกับสำนักไหนก็ได้"

กฎเหล็กของภารกิจนี้:
- ค่าทุกตัว (วัน ดาว ธาตุ สี เลข ฐาน ช่วงดวง ธีม) มาจากบล็อกข้อมูลเท่านั้น
  ไม่มีในบล็อก = ไม่พูดถึง ห้ามประดิษฐ์ค่าเพิ่ม
- ฟรีต้องจบสมบูรณ์: อ่านจบแล้วได้ของครบโดยไม่ต้องจ่าย — ตะขอคือ "มีต่อ" ไม่ใช่ "โดนกั๊ก"
- ห้ามขู่ (จุดหักเห ≠ เคราะห์) ห้ามการันตี ห้ามใบ้หวย — กฎเหล็กกลางคุมเหนือทุกอย่าง
- ความยาวรวม 180-280 คำ อ่านจบในมือถือจอเดียวครึ่ง

BAN LIST — ประโยคต้องห้าม (จริงกับมนุษย์ทุกคน = ห้ามใช้):
"คุณเป็นคนจริงใจ" / "คุณเหนื่อยแต่ไม่ค่อยบอกใคร" / "ภายนอกเข้มแข็งแต่ข้างในอ่อนโยน" /
"ช่วงนี้มีเรื่องให้คิดเยอะ" / "คุณเป็นคนคิดมาก" / "คุณรักครอบครัว" / "ลึก ๆ คุณเหงา" /
"คุณไม่ค่อยไว้ใจใครง่าย ๆ" / "คุณมีศักยภาพที่ยังไม่ถูกใช้" / "อดีตคุณเคยผิดหวังมา"
รวมถึงประโยคทำนองเดียวกันทั้งหมด — เช็กก่อนส่งทุกครั้ง: claim นี้อ้างค่าจากบล็อกข้อมูล
ได้ไหม ถ้าไม่ได้ = ตัดทิ้ง
```

## 4) ตัวอย่างทอง (มาตรฐานเทียบ — จากเฟียร์ ห้ามแก้)

*[เรนเดอร์โดยอาจารย์ดาต้า — ค่าดวงในตัวอย่างคือโครง ค่าจริงต้องมาจากตารางเฟส 3]*

> หมายเหตุ implementer ๒ ข้อ (ตัวอย่างคงเดิมตามเฟียร์ — กติกา production ปรับตามนี้):
> ๑. บรรทัด "นักเชื่อมคน — ตำราว่าปากกับสมองทำงานไว" = ค่า `taksa.deity_trait`
>    จากตาราง engine ไม่ใช่ให้ LLM แต่งเลียนแบบ
> ๒. ประโยคปิด "หรือชวนเพื่อนมา 1 คน..." ใน production ต้องแยกประโยค + ระบุขอบเขต
>    ถามด่วน ตามกติกาจังหวะ 5 ด้านบน — กันคนอ่านเข้าใจว่าชวนเพื่อนแล้วได้คำตอบ
>    เรื่องเดือน (ของ ฿249) ฟรี ซึ่งจะชนกฎ "เครดิตใช้กับ ฿99 เท่านั้น"
>    *(การตีความนี้รอเฟียร์ยืนยันอีกที เพราะแตะถ้อยคำท้ายตัวอย่างทอง)*

```
ผูกดวงเรียบร้อยค่ะ คุณมายด์

1) ฐานดวงของคุณ
คุณเกิดวันพุธ ปีฉลู — ตำราทักษาให้ดาวพุธเป็นดาวประจำตัว ธาตุดิน
คนดาวพุธคือ "นักเชื่อมคน" — ตำราว่าปากกับสมองทำงานไวกว่าคนทั่วไป

2) แก่นตัวตนตามตำรา
- คนฐานพุธ+ฉลู ตัดสินใจช้าแต่เปลี่ยนยาก — ข้อดีคือไม่พลาดซ้ำ ข้อเสียคือเสียโอกาสที่ต้องคว้าเร็ว
- ตำราชี้ว่าดวงคุณ "เงินเข้าทางคน" — งานที่ได้เจอคนเยอะจะไปไกลกว่างานหลังจอ

3) ช่วงที่ผ่านมา
2-3 เดือนหลัง ดวงคุณเดินอยู่ช่วงดาวเสาร์แทรก — ตำราว่าเป็นช่วงที่มักมี
เรื่องงานหรือที่อยู่ให้ต้องเลือกทาง ถ้าคุณเพิ่งผ่านการตัดสินใจใหญ่มา นั่นคือมันค่ะ

4) ของประจำตัวคุณ
สีเสริม: เขียว | เลขประจำดวง: 5 | คำแนะนำจากตำรา: เรื่องที่ลังเลอยู่ตอนนี้
ถ้ามันต้องใช้ "คน" ช่วย — ทางนั้นคือทางของดวงคุณ เดินได้

นี่คือหน้าแรกของตำราคุณค่ะ ทั้งเล่มยังมี: ดวงรายเดือนปีนี้ · จังหวะการเงิน ·
เนื้อคู่-คนคุย · เลขเบอร์มือถือ · ฤกษ์เรื่องสำคัญ

และมีจุดหนึ่งที่ดิฉันเห็นแล้วอยากบอก — ดวงคุณมีจังหวะหักเหเรื่องงานในครึ่งปีหลังนี้
จะระบุเดือนได้ต้องกางดวงรายเดือน (เจาะลึก ฿249)
หรือชวนเพื่อนมา 1 คน รับสิทธิ์ถามต่อฟรี 1 เรื่องค่ะ
```

## 5) ตัวอย่างเทียบเสียงที่สอง (ไพ่ลั่น — ฉบับร่าง ใช้เทียบว่าโครงเดิม+เสียงต่างทำงานยังไง)

*[ค่าโครงเดียวกับตัวอย่างทอง — โครง 5 จังหวะครบ แต่เป็นภาษาไพ่ลั่น]*

```
เปิดหน้าดวงแรกของคุณมายด์แล้วนะ

คุณเกิดวันพุธ ปีฉลู ดาวประจำตัวคือพุธ ธาตุดิน — ตำราเรียกคนดาวนี้ว่า
"นักเชื่อมคน" ปากกับสมองทำงานไวกว่าคนทั่วไป เวลาคุณพูด คนฟัง

ตำราว่าคนฐานนี้สองอย่างชัดมาก: หนึ่ง ตัดสินใจช้าแต่ไม่กลับคำ —
พลาดน้อยแต่ชอบเสียของที่ต้องคว้าไว รู้ตัวใช่ไหม สอง เงินคุณเข้าทาง "คน"
งานที่ขังคุณไว้หลังจอคืองานที่แพ้ทางดวงตัวเอง

ช่วงสองสามเดือนที่ผ่านมา ดวงคุณเดินผ่านช่วงดาวเสาร์แทรก —
ช่วงแบบนี้ตำราว่ามักมีเรื่องงานหรือที่อยู่มาบังคับให้เลือกทาง
ถ้าเพิ่งเลือกอะไรใหญ่ ๆ ไป... ใช่ นั่นแหละ

ของติดตัวคุณ: สีเขียวเสริม เลข 5 ประจำดวง — และคำเดียวจากไพ่:
เรื่องที่ลังเลอยู่ ถ้ามีชื่อคนโผล่มาในหัวตอนคิดถึงมัน ทางนั้นเดินได้

นี่แค่ไพ่ใบแรกของสำรับคุณนะ ทั้งสำรับยังมี ดวงรายเดือนปีนี้ · จังหวะการเงิน ·
เนื้อคู่-คนคุย · เลขเบอร์มือถือ · ฤกษ์เรื่องสำคัญ

แล้วมีใบหนึ่งที่โผล่มาแล้วฉันเก็บปากไว้ไม่อยู่ — ดวงคุณมีจังหวะหักเหเรื่องงาน
ช่วงครึ่งปีหลัง อยากรู้ว่าเดือนไหน ต้องกางดวงรายเดือน (เจาะลึก ฿249)

ยังไม่พร้อมก็ไม่เป็นไร — ชวนเพื่อนมา 1 คน รับสิทธิ์ถามด่วนฟรี 1 เรื่อง
เอาไว้ถามคำถามสั้น 1 คำถามกับสำนักไหนก็ได้
```

## 6) การวัดผล (ตัวเลขตัดสิน ไม่ใช่ความรู้สึก)

- **ตัวชี้วัดเดียว: % ผู้รับผูกดวงฟรี → จ่ายครั้งแรกภายใน ๗ วัน**
  ตั้งต้น 5-8% — ต่ำกว่านั้นแก้จังหวะ 3 (จุดสะดุ้ง) กับจังหวะ 5 (ตะขอ) ก่อนเสมอ
- Event log ต่อ user: `free_reading_delivered` (persona, hook_theme, hook_variant)
  → `first_payment` (sku, เวลาห่างจาก free) → `share_card_sent` → `referral_follow`
- ตาราง conversion รายธีมตะขอ (งาน/รัก/เงิน) — engine เลือกธีมที่แปลงดีสุดต่อ segment
  โดยยังต้องสอดคล้องดวงจริง (เลือกจากธีมที่ตารางดวงอนุญาตเท่านั้น ไม่ฝืนดวงเพื่อยอด)
- จังหวะ 5 ทำ ๒ เวอร์ชันสลับ (A/B) ตั้งแต่วันแรก:
  **A** ปิดด้วยหักเห+เดือน (ตามตัวอย่างทอง) / **B** ปิดด้วยคำถามเปิด
  ("ครึ่งปีหลังนี้มีเรื่องหนึ่งที่ดวงคุณต้องเลือก — อยากรู้ไหมว่าเรื่องไหน")
  วัดที่ตัวชี้วัดเดียวกัน เดือนละรีวิว

## 7) Acceptance tests (เพิ่มจากชุดเดิม)

1. user เดิมขอผูกดวงซ้ำ → ค่าฐาน/ธาตุ/สี/เลขชุดเดิมเป๊ะ (period เดินตามปฏิทินได้)
2. ทุกข้อความฟรีจบด้วยจังหวะ 5 ครบ: แผนที่ + ตะขอ ๑ อัน + ทางเครดิตฟรี
