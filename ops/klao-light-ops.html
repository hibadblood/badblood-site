ห้องนี้มีแค่ 4 สถานะ

ไม่มีสถานะที่ห้า

ปัญหาไม่ใช่ไฟไม่สวย ปัญหาคือทุกคืนห้องหน้าไม่เหมือนกัน เพราะแต่ละคนไล่กดคนละปุ่ม ตัดตัวเลือกทิ้งก่อน แล้วค่อยพูดเรื่องปุ่ม

STATE 0
CLOSED

ไฟทำงาน ขาวสว่าง เห็นพื้นชัด ใช้ตอนทำความสะอาด เช็คสต็อก ซ้อม ไม่ต้องสวย ต้องเห็น

STATE 1
OPEN

ร้านเปิด ยังไม่มีโชว์ ไฟนิ่ง ไม่กระพริบ อ่านเมนูออก เห็นหน้าคนคุยกัน นี่คือสถานะที่ร้านอยู่นานที่สุดในหนึ่งคืน

STATE 2
SHOW

ดีเจ/วงขึ้น ไฟลงมืด เอฟเฟกต์วิ่งตาม BPM ของเดิมทั้งหมดใน show file ทำงานอยู่ชั้นนี้

STATE 3
AFTER

เพลงจบ ไล่แขก ไฟค่อยๆ ขึ้นอุ่นแต่สว่างกว่า OPEN ห้ามกระโดดไปขาว 100 ทันที มันไล่แขกแบบเสียมารยาท

OVERRIDE
PANIC

ขาว 100 ทุกดวง ทับทุกอย่าง ใช้ตอนมีเรื่อง มีคนล้ม ไฟไหม้ ตำรวจเข้า ปุ่มเดียว ไม่ต้องคิด

02

ลำดับเปิด — ห้ามสลับ

~15 นาทีก่อนเปิดประตู

ลำดับนี้ไม่ได้ตั้งเพื่อความเป๊ะ แต่ละข้อกันความพังคนละแบบ ถ้าสลับข้อ 2 กับ 4 ดวงไฟจะรับคำสั่งตอนกำลัง reset ตัวเอง แล้วค้างสีมั่วทั้งคืนโดยไม่มีใครรู้ว่าทำไม

  1. เบรกเกอร์เมน + วงจรไฟเวที
    เปิดตู้ไฟก่อนทุกอย่าง เช็คว่าไม่มีเบรกเกอร์ตัวไหนทริปค้างจากคืนก่อน ถ้ามีตัวทริป ห้ามดันขึ้นแล้วเปิดร้านต่อ — หาเหตุก่อน
  2. ไฟเลี้ยงดวงไฟ / ดิมเมอร์ก่อนคอนโซล
    มูฟวิ่งเฮดต้องได้ home ตัวเองจนจบก่อนที่คอนโซลจะเริ่มยิง DMX รอจนหยุดนิ่งหมดทุกดวง ประมาณ 40–60 วินาที
  3. เฮเซอร์ — เติมน้ำยา แล้วเปิดวอร์ม
    วอร์มใช้เวลา ทำเป็นข้อแรกๆ จะได้มีควันพอดีตอนเปิดประตู เช็คระดับน้ำยาทุกคืน ไม่ใช่ตอนที่มันเตือน
  4. เปิดคอนโซล (เครื่อง onPC) → โหลด show file
    รอให้ Windows ขึ้นจนนิ่ง ปิดหน้าต่างที่เด้งขึ้นมาให้หมด แล้วค่อยเปิด onPC โหลดไฟล์ล่าสุด เช็คชื่อไฟล์ทุกครั้ง ว่าตรงกับที่บันทึกไว้ครั้งสุดท้าย
  5. เช็ค DMX ออกจริง
    ดันแฟเดอร์ HOUSE ขึ้นเล็กน้อย ต้องเห็นดวงไฟขยับ ถ้าไม่ขยับ = สายหลุด/โหนดไม่ติด อย่าเพิ่งไปยุ่งกับคอนโซล ไปดูสายก่อน
  6. Grand Master ขึ้น 100 แล้วล็อกไว้ตรงนั้นห้ามใช้หรี่ไฟ
    Grand Master คือสวิตช์ฉุกเฉิน ไม่ใช่เครื่องมือปรับบรรยากาศ ถ้าใครหรี่มันไว้ 60% แล้วลืม ทั้งคืนจะรู้สึกว่า "ไฟไม่สว่างเหมือนเดิม" โดยหาสาเหตุไม่เจอ อยากหรี่ ใช้แฟเดอร์ HOUSE
  7. กด OPEN
    ห้องเข้าสถานะ OPEN ยืนดูสัก 20 วินาที ให้ทุกดวงเข้าที่ก่อนจะเดินไปทำอย่างอื่น
  8. เพาเวอร์แอมป์ / ลำโพง — ท้ายสุดเสมอ
    เปิดท้ายสุด ปิดก่อนเพื่อน กัน pop ที่กินดอกลำโพง นี่เป็นกฎเสียง ไม่ใช่กฎไฟ แต่มันอยู่ในลำดับเดียวกันเพราะคนกดคือคนเดียวกัน

อ่านแผงนี้ยังไง

  • HOUSE — แฟเดอร์ความสว่างรวมของร้าน อยู่ 100 เกือบตลอด นี่คือตัวที่ให้คนหรี่ ไม่ใช่ Grand Master
  • OPEN / SHOW / AFTER — สามสถานะหลัก กดปุ่ม GO ตัวใดตัวหนึ่ง อีกสองตัวลงเอง ไม่ต้องปิดเอง
  • FX — ชั้นเอฟเฟกต์ที่ทับข้างบน ดันขึ้นเมื่อดีเจขึ้น ลงเมื่อพูดไมค์ คนไม่คุมไฟไม่ต้องแตะ
  • PANIC WHITE — ทับทุกอย่าง ขาวเต็ม ไม่มีเงื่อนไข ควรเป็นปุ่มที่กดถูกได้ในความมืดโดยไม่ต้องมอง — ติดเทปนูนหรือทำเครื่องหมายไว้ที่ปุ่มจริง
  • SPEED — ตัวคุมความเร็วเอฟเฟกต์ ให้ผูกกับ BPM เดียวกับที่ตั้งไว้แล้วในไฟล์ ไม่ต้องมีหลายตัว
กฎเหล็ก

Executor 1–9 บนเพจ 1 เป็นพื้นที่ของ "ร้าน" ห้ามเอาไปเก็บคิวโชว์ ห้ามทับ ห้ามยืมชั่วคราว งานโปรแกรมทั้งหมดไปอยู่ตั้งแต่ 10 ขึ้นไปเหมือนเดิม ถ้าวันไหนมีคนยืมช่องพวกนี้ ระบบทั้งหมดนี้ตายทันที

04

การ์ดติดโต๊ะ

พิมพ์ · ติดข้างคอนโซล

อันนี้คือสิ่งเดียวที่คนเปิดร้านต้องอ่าน ทุกอย่างข้างบนคือเหตุผลเบื้องหลังมัน

เปิดร้าน

5 ขั้น · ประมาณหนึ่งนาที

  1. เปิดเบรกเกอร์ → รอไฟทุกดวงหยุดนิ่ง
    ประมาณหนึ่งนาที อย่ารีบ
  2. เปิดเฮเซอร์
    เช็คน้ำยาก่อน
  3. เปิดคอมพิวเตอร์ → เปิดโปรแกรมไฟ → โหลดไฟล์ล่าสุด
    ปิดหน้าต่างที่เด้งขึ้นมาให้หมดก่อน
  4. ดัน HOUSE ขึ้นสุด → กด GO ที่ OPEN
    แฟเดอร์ที่หนึ่งกับที่สอง
  5. เปิดเครื่องเสียงเป็นอันสุดท้าย
    ตอนปิดร้าน ปิดตัวนี้ก่อนเพื่อน

ปิดร้าน — ย้อนกลับทางเดิม

  • 1. ปิดเครื่องเสียงก่อน
  • 2. กด GO ที่ AFTER ปล่อยไว้จนแขกออกหมด
  • 3. กด CLOSED ทำความสะอาดด้วยไฟขาว
  • 4. ปิดเฮเซอร์ ปิด onPC ให้ Windows shut down จริง ไม่ใช่ปิดฝา
  • 5. ปิดไฟเลี้ยงดวงไฟ แล้วค่อยลงเบรกเกอร์เมน
05

เมื่อพัง — ไล่ทีละขั้น

อย่าข้ามขั้น

คนส่วนใหญ่พอไฟพังจะเริ่มกดมั่ว แล้วทำให้พังหนักกว่าเดิม บันไดสี่ขั้นนี้ไล่จากสาเหตุที่เจอบ่อยที่สุดลงไป

ขั้น 1
เช็คสามอย่างนี้ก่อนแตะอย่างอื่น
Grand Master อยู่ 100 ไหม · แฟเดอร์ HOUSE ขึ้นสุดไหม · คอนโซลอยู่โหมด Blind หรือเปล่า สามข้อนี้คือสาเหตุของ "ไฟดับ" ส่วนใหญ่
ขั้น 2
ล้างของค้าง แล้วเข้าสถานะใหม่
ปิด executor ที่ค้างอยู่ทั้งหมด (ดูคำสั่งในหัวข้อ 06) แล้วกด GO ที่ OPEN ใหม่ ใช้กับอาการ "ไฟค้างสีมั่ว" หรือ "เอฟเฟกต์วิ่งไม่หยุด"
ขั้น 3
ดวงไฟไม่ตอบเลย — ไปดูสาย ไม่ใช่ดูจอ
ถ้าคอนโซลแสดงว่าส่งค่าอยู่แต่ไฟนิ่งสนิท ปัญหาอยู่ที่ DMX node / สาย / ไฟเลี้ยงดวง ไม่ได้อยู่ในคอมพิวเตอร์ การรีสตาร์ท onPC จะไม่ช่วยและกินเวลาไปอีกห้านาที
ขั้นสุดท้าย
ต้องมีไฟที่ไม่ผ่านคอนโซลเลย
อย่างน้อยหนึ่งวงจร — ไฟทางเดิน ไฟบาร์ ไฟทางออก — ต้องต่อกับสวิตช์ผนังตรงๆ ไม่ผ่าน DMX ไม่ผ่าน onPC ถ้าตอนนี้ยังไม่มี นี่คือความเสี่ยงระดับต้องแก้ก่อนเรื่องอื่นทั้งหมด ไม่ใช่เรื่องความสวย เป็นเรื่องความปลอดภัยและใบอนุญาต

07

กฎของเครื่องคอมพิวเตอร์

จากภาพหน้าจอ

ในภาพมีหน้าต่าง OneDrive เด้งทับหน้าจอคอนโซลอยู่ นี่ไม่ใช่เรื่องน่ารำคาญเฉยๆ — หน้าต่างแบบนี้ขโมยโฟกัสคีย์บอร์ดได้ แปลว่าตอนกดคำสั่งกลางโชว์ ตัวอักษรอาจไปลงในหน้าต่างนั้นแทน เครื่องที่ใช้คุมไฟต้องถูกทำให้เงียบสนิท

  • ถอด OneDrive ออก หรืออย่างน้อย sign out และปิดไม่ให้เริ่มพร้อมเครื่อง
  • เปิด Focus assist / Do not disturb ถาวร ไม่ให้มี notification ใดๆ เด้ง
  • Windows Update — ตั้ง active hours ครอบเวลาเปิดร้าน และ pause update ไว้ อย่าให้มันรีสตาร์ทเองตอนตีสอง
  • ปิด sleep และ screen saver ทั้งหมด รวมถึงตอนปิดฝาโน้ตบุ๊ก
  • ไม่ต่ออินเทอร์เน็ตในเครื่องคุมโชว์ ถ้าจำเป็นต้องต่อ ให้ต่อเฉพาะตอนอัปเดตไฟล์แล้วตัดออก
  • เซฟไฟล์แบบมีเวอร์ชัน ตั้งชื่อ KLAO_YYMMDD_v1 ไม่ทับไฟล์เดิม และก๊อปลง USB ที่เสียบคาไว้ทุกครั้งที่แก้
  • UPS สำหรับคอนโซล ไฟกระพริบวินาทีเดียวแล้วเครื่องดับกลางคืนวันศุกร์ คือต้นทุนที่แพงกว่า UPS หลายเท่า
08

ที่ยังไม่รู้

ตอบแล้วผมเติมให้ครบ

ห้าข้อที่ทำให้เอกสารนี้เป็นของจริงแทนที่จะเป็นแบบ

  • รายการดวงไฟ — มีอะไรบ้าง กี่ดวง มูฟวิ่งกี่ตัว พาร์กี่ตัว ถ่ายรูป patch list มาก็ได้
  • มีไฟวงจรแยกที่ไม่ผ่าน DMX ไหม — ข้อนี้สำคัญที่สุด ถ้าไม่มีต้องเพิ่ม
  • ใครเป็นคนเปิดร้านจริง — บาร์เทนเดอร์ ดีเจ หรือคนคุมไฟ คำตอบเปลี่ยนว่าการ์ดต้องละเอียดแค่ไหน
  • ชื่อ show file ปัจจุบัน และ executor 1–9 ว่างจริงหรือเปล่า
  • ตารางคืนหนึ่ง — เปิดกี่โมง ดีเจขึ้นกี่โมง ปิดกี่โมง จะได้ใส่เวลาลงในสถานะแต่ละอัน
